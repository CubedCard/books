# Chapter 6 - Styles of unit testing

## Key Ideas
- Three styles:
    - Communication
    - Output
    - State
- Londen style prefers communication (uses a lot of mocks)
- Classic style prefers state (uses no mocks)
- Both styles use output
- Functional architecture can help when implementing output-based testing

## Core Message
> Try and use output-based testing as much as possible.
