# Chapter 5 - Object Oriented Programming

## Key Ideas

The author describes OO as the introduction of inheritance, encapsulation, and
polymorphism. The first two, however, are not new ideas. The last one,
polymorphism, is also not new, but it is the first time it is properly
implemented. It allows the dependencies to go into the other direction. Not
just down the path, but up as well. This makes clean architecture possible. So
you can have a domain layer that is not dependant on the database, nor the UI. 

## Core Message
> Object-Oriented adds polymorphism.
