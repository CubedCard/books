# Chapter 1 - What Is Design and Architecture?

## Key Ideas
- **Design vs. Architecture** - they are basically the same.
- **More people, less work** - lots of companies suffer from needing more
  people to do less work (per person). This is because of bad architecture.
- **Slow and steady wins the race** - write clean code that will take longer
  and requires less maintenance.
- **Quicker features** - working cleanly should have the result of features
  taking less time to implement, the further the application has been
  developed.

## Core Message
> Working clean is always faster than working dirty.
