# Chapter 11 - The Dependency Inversion Principle

## Key Ideas
The chapter mostly highlights the fact that depending on a class is bad. You
should depend on interfaces. Some are not practical to avoid, like the String
class. DIP is not 100% avoidable. When applied correctly it is what separates
layers from each other. It reminds me of the relationship between the
abstractions in the Domain layer and the implementations in the Infrastructure
layer.

## Core Message
> Use interfaces where possible.
