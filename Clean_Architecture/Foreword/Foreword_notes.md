# Foreword - Notes

The author says that code itself has not changed much since its existence. I
would agree. We have started using more powerful programming languages, but the
code principles are still the same. The author describes how if you would bring
back a programmer of this day and show them the old ways, they will first be
shocked, and then they will know what to do. Same for the other way around.

The thing that changed most, is the hardware. It has become so much more
powerful. For me as a relatively new programmer, the specs that the computers
used to have sound impossibly small. 

Furthermore, this book is about clean architecture. So it is about rules. Those
rules, according to the author, are still the same as they were at the start.
The thing is that nobody knew them and they would be broken very often.

Lastly, according to the writer, the architecture that software is built on, is
more complex than that of a building. Even though it is not visible to the
naked eye, it is very complex. The amount of thought that goes into designing
software can be baffling. Mostly because we cannot look into the future.
