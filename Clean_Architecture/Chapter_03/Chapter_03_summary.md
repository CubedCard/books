# Chapter 3 - Paradigm Overview

## Key Ideas
In this very short chapter, three paradigms are introduced:
1. Structured programming
2. Object-oriented programming
3. Functional programming

All of these do not add any features. On the contrary, they remove
functionality. They add constraints. Clean architecture uses all of these
paradigms.

It makes me think of the architecture tests that I have added to my clean
architecture project. The rules that you add, so that the next developer will
need to obey them. Keeping your architecture intact.

## Core Message
> Paradigms are negative, but good.
