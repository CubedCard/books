# Chapter 9 - Liskov Substitution Principle

## Key Ideas
When using inheritance, the children should comply to the rules. The simplest
example is the square inheriting from a rectangle. Every square is a rectangle,
but not the other way around. The sides of a square need to be changed at the
same time, while the sides of a rectangle can be changed separately. Therefore,
it violates the LSP.

## Core Message
> Make sure inheritance is applied well.
