# Chapter 12 - Components

## Key Ideas
- Brief introduction into components
    - What they are
    - What they do
    - Examples (.jar, .war, .exe, ddl)
- These should run separately and not depend on any other component(s)
    - You should be able to develop for one component, without needing another one
- It used to be hard to link, now linking is easy and cheap

## Core Message
> Components are separate.
