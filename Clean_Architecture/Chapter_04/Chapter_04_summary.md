# Chapter 4 - Structured Programming

## Key Ideas

Structured programming was discovered by Dijkstra. The author goes into great
detail about him. It was first rejected by quite a few people, but now is
implemented in most languages. All using the same components, if / then / else
and do / while. 

Furthermore, the author describes software to be similar to science in a way,
and not to mathematics. Math is provable. You cannot prove anything in science.
You can only try to do the opposite. You can disprove something, and if it
cannot be disproved, it is probably (close to) the truth. 

Software works in the same way. We use automated testing to prove that the code
is not broken. When all tests are passing, it does not mean that there are no
problems in the code. 

## Core Message
> Software is like science. Unprovable.
